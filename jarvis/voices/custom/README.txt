Сюда кладите свои записи голоса Джарвиса (mp3 или wav).
Имя файла = какая это фраза. Можно несколько вариантов: listening.mp3, listening_2.mp3, listening_3.mp3 —
Джарвис будет выбирать случайный. Если записи нет, фразу скажет выбранный голос.

greeting       — приветствие при запуске («К вашим услугам, сэр»)
listening      — ответ на «Джарвис» («Да, сэр?»)
opening        — «Открываю, сэр»
searching      — «Ищу, сэр»
youtube        — «Ищу на ютубе»
thinking       — «Секунду, сэр» (пока ИИ думает)
sent           — «Отправлено, сэр»
cancelled      — «Отменено, сэр»
done           — «Готово, сэр»
stop           — «Обращайтесь, сэр» (конец разговора)
bye            — «Отключаюсь. До встречи, сэр»
dictation_on   — начало диктовки
dictation_off  — конец диктовки
no_messages    — «Новых сообщений нет, сэр»
error          — «Боюсь, не получилось, сэр»
