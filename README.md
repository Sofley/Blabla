# NexusTrade — учёт ВЭД-контрактов Back-to-Back

Кросс-платформенное приложение на Flutter (Android / iOS) для учета международных
торговых сделок по схеме Back-to-Back: два связанных, но строго раздельных контракта.

| Контракт | Стороны |
|---|---|
| **Контракт №1** | Покупатель (Buyer) ↔ Промежуточная компания (Intermediary) |
| **Контракт №2** | Промежуточная компания (Intermediary) ↔ Продавец / Завод (Seller) |

## Возможности

- **Раздельные контракты.** Каждый контракт — отдельная вкладка с собственной формой и своими
  полями: номер, дата заключения, участники, стоимость товара, логистика, агентские, НДС,
  примечания. Данные контрактов не смешиваются ни в модели, ни в UI.
- **Финансовый калькулятор** в каждом контракте:
  - стоимость закупа товара в валюте контракта (CNY, USD, EUR, RUB, UZS, KZT, AED) и курс на дату заключения;
  - логистика: транспорт, фрахт, портовые сборы (USD/EUR);
  - агентские услуги — по умолчанию 9%, редактируется;
  - НДС — по умолчанию 9%, редактируется или отключается (0%).
- **Калькулятор чистой прибыли** по сделке (все суммы — в USD по курсам на даты заключения):
  ```
  goods     = стоимость товара / курс
  logistics = (транспорт + фрахт + портовые сборы) / курс
  agency    = goods × агентские%
  net       = goods + logistics + agency
  vat       = net × НДС%
  total     = net + vat

  Оборот         = Контракт №1 total
  Чистая прибыль = Контракт №1 net (без НДС) − Контракт №2 total
  Маржа          = Чистая прибыль / Контракт №1 net
  ```
- **Комментарии / Примечания (Remarks / Notes)** в каждом контракте.
- **Трекер статусов:** Контракт подписан → Предоплата → Оплата заводу в CNY → В пути → Закрыт
  (с датами этапов; этап меняется нажатием).
- **Дашборд:** месячная аналитика — количество контрактов, оборот, чистая прибыль, маржа,
  график прибыли за 6 месяцев, распределение по статусам.
- **Дизайн «Financial Minimalism»**, светлая / темная / системная тема.
- **Локализация:** русский и английский (или язык системы).
- **Локальная БД Hive** — все данные хранятся только на устройстве.

## Новое в версии 1.1

- **Регистрация** по электронной почте или номеру телефона с паролем (PBKDF2-SHA256).
  Быстрый вход: PIN-код из 4 или 6 цифр, графический ключ или только пароль.
  Блокировка после 5 неверных попыток и при уходе приложения в фон больше чем на 1 минуту.
- **Шифрование данных**: все записи Hive зашифрованы AES-256, ключ хранится в Android Keystore / iOS Keychain.
- **Калькулятор цены** (вкладка «Цена»): цена EXW + логистика + агенту % от закупки + наша прибыль,
  возврат НДС посреднику (%, можно отключить). Расчёты сохраняются, из расчёта создаётся сделка.
  ```
  агенту/ед.       = EXW × агент%
  цена продажи/ед. = EXW + логистика + агенту + прибыль
  возврат НДС/ед.  = EXW × возврат%
  прибыль итого    = (прибыль + возврат НДС) × количество
  ```
  Пример: 0,15 + 0,10 + 0,0135 + 0,05 = **0,3135 $/шт**; при 500 000 шт прибыль 25 000 + 6 750 = **31 750 $**.
- **Цена за единицу и количество** в контрактах; **возврат НДС** в Контракте №2 (база: товар или итог)
  и отметка «Возврат НДС получен». Прибыль сделки = Контракт №1 без НДС − Контракт №2 + возврат НДС.
- **Экспорт в PDF, Excel и Word**: отчёт по сделке, реестр сделок за месяц или за всё время, расчёт цены.
  Файлы можно сохранить или отправить (почта, мессенджеры, облако).
- **Резервная копия** всех данных в JSON-файл и восстановление из него.

## Новое в версии 2.1

- **Формула чистой прибыли:** Выручка от покупателя (без НДС) − Выплата заводу − Логистика − Агентские
  + НДС-бонус (только если включён переключатель «Добавлять НДС-бонус в чистую прибыль»).
- **НДС-бонус:** возврат НДС = закуп у завода (FOB) × ставка (9%, редактируется); ваша доля 0–100%
  (по умолчанию **50%**); переключатель по умолчанию **выключен** — бонус показывается справочно.
  Блок расположен в самом низу расчётов. Старые сделки сохраняют прежнюю прибыль (доля 100%, вкл.).
- **Два режима сделки** (переключатель в верхней панели редактора): **Back-to-Back** (два контракта) и
  **Трёхсторонний единый контракт** (Покупатель ⇄ Завод ⇄ ваша компания) со статусами
  Buyer & Importer / Payer / Principal-Commission Agent и подсказками.
- **Конфиденциальность:** в Контракте №1 нет логистики и агентских; документ **«для покупателя»**
  (PDF/Excel/Word) содержит только цену контракта. Цену можно задать вручную или маржой (% от суммы
  завода или суммой) — сумма заводу и прибыль считаются автоматически.
- **Калькулятор цены:** закупка за тонну, логистика за партию, режим «от цены покупателя»
  (пример: 1 550 $/т × 22 т, логистика 5 200 $, агент 9%, цена 2,30 $/кг → прибыль 8 231 $).
- **7 языков:** Ўзбек (кирилл), O‘zbek (lotin), Русский, English, Srpski (latinica), Српски (ћирилица), 中文.
- **Заставка** с логотипом и случайным слоганом (7 на каждый язык; для китайского — торговые изречения).
- **Офлайн AI-ассистент:** маржа, логистика, цена безубыточности, НДС-бонус, агентские, напоминание
  о расчётах и курсах старше 3 дней. Онлайн-режим — позже.
- **PDF с иероглифами** (шрифт Noto Sans SC).

## Новое в версии 2.0 (NexusTrade)

- **Новое имя и логотип** NexusTrade (иконка Android/iOS, экран входа, заставка).
- **Курсы и тарифы** (вкладка «Курсы»):
  - официальные курсы **ЦБ Узбекистана (CBU)** — загружаются с cbu.uz, сохраняются для работы без интернета;
  - **PBOC** — курсы вводятся вручную (у PBOC нет открытого API), с подсказкой кросс-курса по CBU;
  - кросс-курс USD/CNY и **конвертер валют**; кнопка «Курс CBU/PBOC» в контрактах и калькуляторе цены;
  - **тарифная сетка логистики**: направления, вид транспорта, контейнер, цена от–до, срок в днях; кнопка «Из тарифов» в калькуляторе цены.
- **Чат по каждой сделке**: сообщения от имени «Я / Покупатель / Продавец / Агент / Менеджер», автоматические статус-сообщения
  при создании сделки и смене этапа, отправка переписки через «Поделиться».
- **Режим наблюдателя (Observer)**: только просмотр, жёлтая плашка-индикатор, для выхода нужен пароль владельца.
- **Оформление (Galaxy style)**: Светлая / **AMOLED** тёмная / Авто, акцентный цвет **Teal, Amber, Blue, Purple**,
  **фон из галереи** с регулировкой видимости и размытия.
- Структура сделки **Покупатель ⇄ Посредник ⇄ Продавец** в карточке сделки.
- Резервная копия включает тарифы, чат и курсы PBOC.

## Новое в версии 1.2

Калькулятор цены считается по шагам, каждую цифру можно менять:

1. Цена за товар (EXW) за единицу
2. Количество / объём
3. Логистика — за единицу **или** за всю партию
4. Агентская комиссия, % от цены товара
5. НДС, % от (товар + логистика + агентская) — включается/выключается
6. Моя прибыль / мои комиссионные — сумма за единицу **или** % от себестоимости (шаги 1–5)

Цена продажи = 1 + 3 + 4 + 5 + 6. Возврат НДС посреднику прибавляется к прибыли.
Сделка, созданная из расчёта, даёт ту же прибыль (проверено тестами).

## Публикация

**Google Play**
1. Создайте ключ: `keytool -genkey -v -keystore ~/upload-keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload`
2. Создайте `android/key.properties` (не коммитится):
   ```
   storePassword=...
   keyPassword=...
   keyAlias=upload
   storeFile=/абсолютный/путь/upload-keystore.jks
   ```
3. `flutter build appbundle --release` → `build/app/outputs/bundle/release/app-release.aab`.

**App Store**
1. Откройте `ios/Runner.xcworkspace` в Xcode, укажите Team и Bundle Identifier.
2. `flutter build ipa --release`, загрузите через Xcode Organizer или Transporter.

Перед публикацией замените иконки приложения (`android/app/src/main/res/mipmap-*`,
`ios/Runner/Assets.xcassets/AppIcon.appiconset`) и при необходимости идентификатор
`uz.nexustrade.app`.
