# NexusTrade 3.0 — Этап 1 (офлайн)

## 1. Что изменено

### Безопасность и доступ
- Режим Observer удалён. Вместо него **5 ролей**: Владелец, Администратор, Менеджер, Партнёр, Клиент.
  Профили создаёт владелец (или администратор) в Настройки → Работа → Пользователи, у каждого свой PIN.
  На экране входа выбирается профиль; кнопка «Сменить пользователя» есть внизу экрана.
- Внутренние финансы (прибыль, агентские, логистика, НДС агента, возврат НДС, маржа, внутренний отчёт,
  калькулятор цены, ассистент, месячная прибыль, реестр, резервные копии) видит **только владелец**.
  Ограничение сделано **в слое данных**: для других ролей сделка приходит уже очищенной
  (`AccessPolicy.redact`), поэтому эти данные не попадают ни на экран, ни в экспорт, ни в отчёт.
  Запрещённые действия отклоняются в контроллере, даже если экран их показал бы.
  - Клиент: только свои сделки — номер, стороны, товар, количество, цена и сумма своего контракта,
    этапы, условия поставки. Завод в схеме Back-to-Back клиенту не виден. Экспорт — только документ покупателя.
  - Партнёр: назначенные сделки, основная информация и этапы, без сумм.
  - Менеджер: назначенные сделки, этапы, документы, условия поставки, чат.
  - Администратор: все сделки, пользователи, клиенты, этапы, документы, корзина.
- Документы сделки хранятся **зашифрованными** (AES-256-GCM, ключ в Android Keystore).
  Временная копия файла при «Поделиться» удаляется через 2 минуты.
- Защита от скриншотов **не включалась** (по ТЗ).

### Удаление
- Удаление переносит сделку в **корзину** (Настройки → Работа → Корзина) с подтверждением и кнопкой «Отменить».
- Через **15 дней** сделка удаляется окончательно вместе с документами и чатом
  (проверяется при каждом запуске). «Удалить навсегда» доступно только владельцу.
- В уже сделанных резервных копиях сделка остаётся; при восстановлении копии правило 15 дней применяется заново.

### Финансы (утверждённые правила)
- **Агентские**: переключатель ВКЛ / ВЫКЛ; ввод **процентом от себестоимости товара** (0–100 %,
  независимо от EXW или FOB, логистика в базу не входит) или **фиксированной суммой**. По умолчанию 8 %.
- **НДС на услуги агента**: переключатель ВКЛ / ВЫКЛ (по умолчанию ВЫКЛ). При ВКЛ входит в цену;
  если ставка не введена — «Не задано», ставка не подставляется, в расчёте видна пометка «Рассчитано без».
- **Логистика**: суммы вручную, **за тонну** (ставка × вес партии) или **за фуру / контейнер**
  (ставка × количество). Справочник типов: контейнер 20 футов, контейнер 40 футов, фура 22 т, фура 25 т;
  можно править и добавлять свои (Настройки → Работа → Типы транспорта). Количество машин считается по весу
  с округлением вверх и правится вручную; у контейнеров вместимость не задана, пока вы её не введёте.
- **Итоговая цена = себестоимость товара + логистика + агентские (если ВКЛ) + НДС агента (если ВКЛ) + выгода.**
- Прибыль по умолчанию **0,33 USD за единицу**. Цену и прибыль можно задать вручную в каждой сделке
  (режим «Прибыль/ед.» считает цену; режим «Вручную» — прибыль считается от цены).
- Возврат НДС **9 % от FOB**, его получает китайская компания-посредник; **ваша доля по умолчанию 0 %**
  (Настройки → Значения по умолчанию). Автоматических 50 % больше нет.
- **Курсовая разница при закрытии**: поле «Курс на дату закрытия», результат показывается отдельно
  и в прибыль не входит.
- НДС закупки по умолчанию выключен: 2,30 USD/кг — конечная цена.

### Модель данных
- Необязательные суммы (транспорт, фрахт, портовые, логистика в расчёте) имеют три состояния:
  **пусто («Не задано») / подтверждённый 0 / значение**. Кнопка «0» подтверждает ноль.
- Миграция: старые нули в этих полях стали «Не задано». Реальные значения не тронуты.
- Отчёты PDF/Excel/Word: пустые поля не печатаются, подтверждённый ноль печатается как 0.

### Этапы
- Подписание → Предоплата → Загрузка → **Оплата (100 % от покупателя)** → Закрыт.
- Перенос старых этапов: «Оплата заводу в CNY» → Предоплата, «В пути» → Загрузка.
  Все даты сохранены, в **Истории этапов** старые названия показаны как были записаны.
- Каждая смена этапа записывается в историю с датой и именем пользователя.

### Клиенты и отчёты
- Справочник клиентов: компания, контактное лицо, телефон, почта, адрес, заметки, сделки, суммы.
  При миграции покупатели из старых сделок стали клиентами автоматически.
- Главная: «Прибыль по клиентам» за месяц. Месячный отчёт (экспорт) содержит общую прибыль, прибыль по клиентам,
  число сделок, общую сумму. Сделка относится к **месяцу подписания** Контракта №1.

### Резервные копии (вариант B)
- Копия шифруется **AES-256-GCM**, ключ получается из пароля аккаунта через **Argon2id** (19 МБ, 2 прохода).
  Пароль не хранится нигде; хранится только производный ключ в Android Keystore.
- Раз в неделю копия создаётся автоматически, затем приложение предлагает **«Сохранить в Google Drive»** в одно нажатие.
- Видна дата последней копии и дата последнего сохранения вне телефона.
- Ручная копия, сохранение файлом, восстановление. Перед восстановлением текущие данные сохраняются в отдельную копию.
- Копии версии 2.x (без шифрования) тоже восстанавливаются.
- При регистрации показано предупреждение: пароль защищает и вход, и копии.

### Досье сделки и номер (по решениям от 12.11)
- **Номер электронной сделки** NT-ГГГГ-NNNN присваивается автоматически, можно изменить вручную (проверка уникальности).
  Номера не используются повторно даже после удаления сделки. Старым сделкам номера даны по дате создания.
- **Двусторонний контракт** (Покупатель ↔ Продавец) — третий режим сделки рядом с Back-to-Back и трёхсторонним.
- **Снимки расчёта** при подписании (первое сохранение) и при закрытии: выручка, закупка, логистика,
  агентские, НДС агента, прибыль — фиксируются и потом не меняются. Видит только владелец.
- **Раздел «Официальный контракт»**: номер и дата договора, клиент, номер сделки, статус «прикреплён / не прикреплён»,
  просмотр, скачивание, добавление, замена.
- **Досье документов** по категориям: основной договор, Invoice, приложения, доп. соглашения, корректировки, прочие.
  У каждого документа номер, дата, статус (Действующий / Заменённый / Аннулированный), связь с основным договором,
  история версий (замена файла не удаляет прежнюю версию). Корректировка помечает исправленный документ как «Заменённый».
- Форматы: PDF, DOC, DOCX, XLS, XLSX, JPG, JPEG, PNG. Картинки открываются внутри приложения, остальное —
  установленным на телефоне приложением. **Лимит размера снят.**
- Клиенту и партнёру видны только документы с отметкой «Показывать клиенту и партнёру» (по умолчанию выкл.).
- Поиск сделок по номеру сделки, товару, номерам договора / Invoice / доп. соглашений и названиям документов.
- **Резервная копия нового формата (v5)**: потоковая запись по 1 МБ, документы не держатся в памяти целиком;
  каждая порция зашифрована и защищена от подмены и обрезки. Перед восстановлением файл проверяется полностью —
  если он повреждён или загружен не до конца, данные на телефоне не меняются. Копии 3.0 (v4) и 2.x читаются.
- Расшифрованные временные копии файлов удаляются при каждом запуске.

### Виджет на рабочем столе
- Активные контракты, этап выбранного контракта (полоса из 5 этапов), сумма контракта, прибыль.
- Выбор сделки: кнопка «Показывать в виджете» на экране сделки; иначе — последняя активная.
- Прибыль — только для владельца; переключатель «Скрыть суммы в виджете». Подробно: `docs/WIDGET.md`.
- Android готов; iOS — код WidgetKit приложен, подключается в Xcode на Mac (здесь не собирался).

### Прочее
- Напоминания для каждого пользователя: выкл / ежедневно / каждые 3 дня / еженедельно + время.
- Примеры тарифов удалены (только если вы их не меняли). Раздел «Онлайн-тарифы» виден, но неактивен до этапа 3.
- Заставка: слоган появляется на 1,5 с, полностью виден с 1,9 с до 5,0 с (**3,1 с**), не меняется и не прыгает.
  Причина прежней ошибки: экран заставки пересоздавался при смене статуса входа — исправлено.
- Постоянный ключ подписи; релизная сборка без ключа остановится с ошибкой (см. `docs/SIGNING.md`).

## 3. Как обновиться с 2.x (один раз)
2.x подписаны временным ключом, поэтому 3.0 нельзя поставить поверх:
1. В 2.1: Настройки → Данные → Резервная копия → сохранить файл (`.json`).
2. Удалить старое приложение.
3. Установить 3.0, зарегистрироваться (лучше тем же паролем).
4. Настройки → Данные → Резервные копии → Восстановить из файла → выбрать `.json`.
Все следующие версии ставятся поверх без потери данных.

## 4. Резервные копии — инструкция
- **Создать**: Настройки → Данные → Резервные копии → «Сохранить в Google Drive» (выберите «Диск») или «Сохранить файлом».
  Файл `.ntb` содержит сделки, клиентов, настройки и все документы со всеми версиями.
- **Автоматически**: раз в 7 дней при входе владельца; появится окно «Сохранить в Google Drive».
- **Восстановить**: там же «Восстановить из файла» → файл `.ntb` → пароль, с которым копия создана.
- **Важно**: без пароля копию открыть нельзя никак. После смены пароля старые копии открываются старым паролем.
- Храните копии минимум в двух местах (Google Drive + компьютер/флешка).

## 5. Что осталось (следующие этапы)
- Этап 2: мессенджер на Supabase (сообщения, документы, чаты по сделкам, роли на сервере).
- Этап 3: платные онлайн-тарифы логистики (после инвестиций).
- Этап 4: свой сервер: регистрация с кодом подтверждения, синхронизация, центральное хранение, права на сервере.
  Сейчас роли работают **на одном телефоне** (общий телефон / планшет); у каждого человека на своём телефоне
  будет доступ только после сервера.
- Не вошло в Этап 1: архив-снимок закрытых сделок, журнал всех изменений (кроме истории этапов), история курсов.
- Переводы uz/sr/zh сделаны ИИ — желательна вычитка носителем.
- Юридический вопрос локализации персональных данных в Узбекистане — проверить с юристом.

## 6. Сервер: облако или свой — простыми словами
| | Облако (Supabase / Firebase / VPS) | Свой сервер в офисе |
|---|---|---|
| Что это | арендуете готовые мощности у провайдера | покупаете компьютер-сервер и держите у себя |
| Старт | 0–25 $/мес (Supabase Free / Pro 25 $), VPS 5–20 $/мес | 800–2 500 $ за сервер + ИБП + статический IP |
| Ежемесячно | 25–100 $ при росте | интернет, электричество, администратор (от 200–500 $/мес) |
| Надёжность | резервирование и бэкапы у провайдера | всё на вас: поломка, свет, интернет |
| Безопасность | шифрование, обновления делает провайдер | обновления и защиту делаете сами |
| Где лежат данные | в дата-центре провайдера (часто ЕС/США) | у вас, в Узбекистане |
| Подходит | быстро стартовать, мало людей, без админа | если закон требует хранить данные в стране |

Рекомендация: начать с облака (Supabase Pro ≈ 25 $/мес) для этапа 2. Если юрист подтвердит,
что персональные данные граждан Узбекистана нужно хранить в стране, — арендовать VPS в местном
дата-центре (≈ 20–60 $/мес) вместо своего сервера в офисе.
