# NexusTrade 3.0.0 — установка и проверка на телефоне

## Какой файл ставить
- **NexusTrade-v3.0.0-lite.apk** (34 МБ) — для современных телефонов (64-bit ARM, почти все Android 2018+). Рекомендуется.
- **NexusTrade-v3.0.0.apk** (81 МБ) — универсальный, если lite не устанавливается.
Всегда ставьте один и тот же вариант: следующие версии будут выходить в обоих вариантах.

Обе подписаны постоянным ключом (SHA-256 сертификата `83:E0:AA:E3:…:92:8F`).

## Переход с 2.x (один раз)
1. В старой версии: Настройки → Данные → Резервная копия → сохранить `.json` (например, в Google Drive или «Загрузки»).
2. Удалите старое приложение (иначе установка 3.0 выдаст ошибку подписи).
3. Установите 3.0, зарегистрируйтесь. Прочитайте предупреждение о пароле.
4. Настройки → Данные → Резервные копии → **Восстановить из файла** → выберите `.json`.

## Чек-лист проверки (отметьте каждый пункт)
| # | Проверка | Ожидаемый результат |
|---|---|---|
| 1 | Запуск | Заставка ~5 с, слоган виден ≥ 3 с и не меняется |
| 2 | Регистрация / вход / PIN | Вход работает, после 5 ошибок — блокировка |
| 3 | Данные из 2.x | После восстановления все сделки, у старых сделок номера NT-…, этапы и история на месте |
| 4 | Контрольный пример | FOB 1 600 $/т, 22 т, логистика 5 400 $, агент 8 %, цена 2,30 → прибыль 7 184 $ |
| 5 | Прибыль 0,33 $/кг | Режим «Прибыль/ед.» → цена 2,3035 $/кг |
| 6 | Пустые поля | Пустая логистика — «Не задано», кнопка «0» подтверждает ноль |
| 7 | Двусторонний контракт | Создать сделку в режиме «Двусторонний», стороны: Покупатель ↔ Продавец |
| 8 | Снимки расчёта | У новой сделки — «При подписании»; после «Закрыт» — «При закрытии» |
| 9 | Официальный контракт | Добавить PDF договора с номером и датой → «Контракт прикреплён»; Просмотр, Скачать, Заменить → 2 версии |
| 10 | Досье | Добавить Invoice, доп. соглашение, корректировку Invoice → исходный Invoice «Заменённый» |
| 11 | Поиск | Найти сделку по номеру Invoice и по товару |
| 12 | Роли | Создать профили Менеджер и Клиент; войти как каждый — нет прибыли, агентских, калькулятора; клиент видит только свою сделку и документы с отметкой «Показывать клиенту» |
| 13 | Корзина | Удалить сделку → в корзине, «Восстановить» работает |
| 14 | Резервная копия | «Сохранить в Google Drive» → файл `.ntb` на Диске; дата последней копии обновилась |
| 15 | Восстановление | Восстановить `.ntb` с паролем: сделки и документы на месте; с неверным паролем — отказ |
| 16 | Напоминания | Включить «Ежедневно» на ближайшее время → уведомление пришло |
| 17 | Виджет | Добавить виджет NexusTrade: число контрактов, этап, сумма, прибыль; «Скрыть суммы» → точки |
| 18 | Скриншот | Скриншот экрана делается (не заблокирован) |
| 19 | Обновление поверх | Следующую версию поставить поверх 3.0 без удаления — данные сохраняются |

Если какой-то пункт не работает — пришлите номер пункта, модель телефона и версию Android (скриншот приветствуется).
