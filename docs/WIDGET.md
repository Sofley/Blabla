# Виджет NexusTrade на рабочем столе

Показывает:
1. **Количество активных контрактов** — все сделки, кроме закрытых и удалённых в корзину.
2. **Этап выбранного контракта** — полоса прогресса (5 этапов) и название этапа, например «Загрузка · 3/5».
3. **Сумму контракта** — сумма Контракта №1 (цена × количество) в валюте контракта.
4. **Прибыль** — чистая прибыль по сделке в USD (зелёная или красная).

Какая сделка показывается: на экране сделки кнопка «Показывать в виджете».
Если сделка не выбрана, показывается последняя активная.
Нажатие на виджет открывает приложение (с вводом PIN / пароля).

## Безопасность
- Виджет виден **без разблокировки телефона**. В Настройках → «Виджет на рабочем столе» есть переключатель
  **«Скрыть суммы в виджете»**: тогда вместо суммы и прибыли показываются точки.
- **Прибыль** выводится только когда в приложении работает владелец. Для других ролей — точки;
  партнёр не видит и сумму. Это то же правило доступа, что и в приложении.
- Чтобы система могла нарисовать виджет, отображаемые строки (номер сделки, клиент, этап, сумма, прибыль)
  хранятся в обычных настройках виджета, **без шифрования**. Остальные данные приложения остаются зашифрованы.
  Если это неприемлемо — включите «Скрыть суммы в виджете».

## Android
Готово: долгое нажатие на рабочем столе → Виджеты → NexusTrade (размер 4×2, можно растягивать).
Код: `android/app/src/main/kotlin/.../NexusWidgetProvider.kt`, `res/layout/nexus_widget.xml`.

## iOS (нужен Mac с Xcode; в этой среде не собирался)
1. Откройте `ios/Runner.xcworkspace`.
2. File → New → Target → **Widget Extension**, имя `NexusWidget` (без Live Activity и без Configuration Intent).
3. Замените созданный Swift-файл на `ios/NexusWidget/NexusWidget.swift`.
4. Для **Runner** и **NexusWidget**: Signing & Capabilities → + App Groups → `group.uz.nexustrade.app`.
5. Deployment target расширения — iOS 17 (используется `containerBackground`).
6. Соберите и запустите; затем добавьте виджет на рабочий стол (размер «средний»).
