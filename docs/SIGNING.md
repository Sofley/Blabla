# Постоянный ключ подписи NexusTrade (Android)

Все обновления приложения должны быть подписаны **одним и тем же** ключом.
Если ключ потерян, телефон не установит новую версию поверх старой, а Google Play
не примет обновление. Поэтому ключ хранится особенно бережно.

## Два файла (выдаются отдельно, в репозитории их НЕТ)

| Файл | Что внутри |
|---|---|
| `nexustrade-release.jks` | сам ключ (хранилище JKS, RSA 4096, срок 30 лет) |
| `nexustrade-release-credentials.txt` | alias, пароль хранилища, пароль ключа, отпечаток SHA-256 |

Отпечаток сертификата (SHA-256, не секрет):
`83:E0:AA:E3:CA:54:74:B0:12:8A:F7:57:25:F6:28:E0:83:5F:ED:90:F5:2B:A2:00:45:41:BB:A6:C2:8D:92:8F`

## Как хранить

1. Сделайте **минимум 2 копии** каждого файла в разных местах
   (например, флешка в сейфе + менеджер паролей / зашифрованный облачный диск).
2. **Не храните оба файла рядом** в одном незащищённом месте: ключ без паролей бесполезен
   для злоумышленника, пароли без ключа — тоже.
3. Пароли удобно держать в менеджере паролей (Bitwarden, 1Password, KeePassXC).
4. Не отправляйте файлы в общие чаты, не коммитьте в git, не прикладывайте к APK.
5. Раз в год проверяйте, что копии открываются (`keytool -list -keystore nexustrade-release.jks`).

## Как собрать релиз

Создайте файл `android/key.properties` (он в `.gitignore`):

```
storePassword=<пароль хранилища>
keyPassword=<пароль ключа>
keyAlias=nexustrade
storeFile=/полный/путь/к/nexustrade-release.jks
```

Затем `flutter build apk --release`. Без ключа релизная сборка **останавливается с ошибкой**,
чтобы случайно не выпустить APK с временным ключом. Тестовую сборку можно сделать явно:
`NEXUS_ALLOW_DEBUG_SIGNING=1 flutter build apk --release` (такой APK не обновит релизную версию).

### GitHub Actions
В Settings → Secrets and variables → Actions добавьте:
`NEXUS_KEYSTORE_BASE64` (вывод `base64 -w0 nexustrade-release.jks`), `NEXUS_STORE_PASSWORD`,
`NEXUS_KEY_PASSWORD`, `NEXUS_KEY_ALIAS` = `nexustrade`.

## Переход с версии 2.x (одноразово)

Версии до 3.0 подписаны временным (отладочным) ключом, поэтому 3.0 нельзя поставить поверх:
1. В старой версии: Настройки → Данные → Резервная копия → сохраните файл.
2. Удалите старое приложение.
3. Установите NexusTrade 3.0, зарегистрируйтесь, Настройки → Данные → Восстановить.
Все последующие версии ставятся поверх без потери данных.

## Google Play
При публикации включите Play App Signing и загрузите этот ключ как **upload key**.
