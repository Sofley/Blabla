Как обновить каталог на сайте

  1. Измените товары на этой странице: добавьте, исправьте, удалите, поменяйте порядок.
  2. Если есть фото — загрузите их в папку фото на GitHub: открыть папку для загрузки.
  3. Нажмите «Скопировать каталог», откройте файл каталога на GitHub, выделите всё (Ctrl+A), вставьте (Ctrl+V) и нажмите зелёную кнопку Commit changes.
  4. Через 1–2 минуты сайт обновится сам.
