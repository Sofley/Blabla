# Luxe Hardware — сайт-визитка фурнитуры

Одностраничный сайт: каталог с ценами и описаниями, выбор покрытия, заявка
прямо в Telegram продавцу и панель статистики «кто и откуда пришёл».

Без фреймворков и внешних зависимостей: нужен только **Node.js 20.12+** (лучше 22).

```
luxe-hardware/
├── server.js          сервер: сайт, заявки → Telegram, статистика, /admin
├── public/            сам сайт
│   ├── config.js      ← ВСЕ контакты, соцсети и счётчики меняются здесь
│   ├── index.html
│   ├── styles.css
│   ├── app.js         каталог (цены, описания — массив PRODUCTS), форма, аналитика
│   └── privacy.html   политика ПДн (шаблон — заполнить реквизиты)
├── admin/             панель статистики (только по паролю)
├── test/              автотесты: npm test
└── .env.example       секреты: токен бота, пароль админки
```

## Запуск

```bash
cp .env.example .env     # заполнить
npm start                # http://localhost:3000, админка — /admin
```

## Подключение Telegram (5 минут)

1. В Telegram открыть **@BotFather** → `/newbot` → получить токен → вставить в `TELEGRAM_BOT_TOKEN`.
2. Написать своему боту любое сообщение (или добавить бота в группу менеджеров).
3. Открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, найти `"chat":{"id": ...}` → в `TELEGRAM_CHAT_ID`.
4. Перезапустить сервер. Каждая заявка придёт сообщением с кнопкой **«Написать @клиенту»** — один тап, и вы в чате с клиентом.
5. (Необязательно) команды статистики прямо в Telegram — `/stats`, `/stats 30`, `/leads`:
   ```bash
   curl "https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://ВАШ-ДОМЕН/api/telegram/<TELEGRAM_WEBHOOK_SECRET>&secret_token=<TELEGRAM_WEBHOOK_SECRET>"
   ```

Клиент со своей стороны пишет менеджеру напрямую кнопкой «Написать в Telegram»:
текст сообщения уже подставлен, а из карточки товара — с артикулом и покрытием.

## Статистика: откуда приходят люди

Панель `/admin` (логин/пароль из `.env`) показывает: визиты, посетителей, заявки, конверсию;
источники — **Instagram, Telegram, YouTube, Google**, Яндекс, ВК, прямые заходы, другие сайты;
какие товары смотрят, нажатия на Telegram/телефон/почту, устройства, регион, кампании. Заявки выгружаются в CSV.

**Главное правило:** Instagram и Telegram часто не передают, откуда пришёл человек.
Поэтому во всех соцсетях ставьте ссылку **с UTM-меткой**:

| Где ссылка | Ссылка |
|---|---|
| Шапка профиля Instagram | `https://сайт.ru/?utm_source=instagram&utm_medium=bio` |
| Telegram-канал, пост | `https://сайт.ru/?utm_source=telegram&utm_medium=post&utm_campaign=novinki_noyabr` |
| Описание видео YouTube | `https://сайт.ru/?utm_source=youtube&utm_medium=video&utm_campaign=obzor_karabinov` |
| Карточка Google Карт | `https://сайт.ru/?utm_source=google&utm_medium=maps` |

Источник запоминается и **подписывается в каждой заявке** — видно, какая соцсеть приносит не просто клики, а клиентов.

Для глубокой аналитики (карта кликов, запись сессий, география по IP) впишите ID **Яндекс Метрики**
и/или **Google Analytics 4** в `public/config.js` — счётчики подключатся сами, цели (`tg_click`, `lead_submit` и др.) уйдут туда же.

## Деплой

Любой VPS в РФ (Timeweb, Selectel, Beget VPS) + Nginx/Caddy с HTTPS, сервер запускается через systemd или pm2.
За прокси поставьте `TRUST_PROXY=1`. Данные — в папке `data/` (JSON Lines), её стоит бэкапить.

## Что заменить перед запуском

- [ ] Контакты и ссылки на соцсети — `public/config.js`
- [ ] Цены, размеры, описания — массив `PRODUCTS` в `public/app.js`
- [ ] Реквизиты в `public/privacy.html` + уведомление в Роскомнадзор (pd.rkn.gov.ru)
- [ ] Заменить векторные иллюстрации настоящими фото изделий (в карточке: деталь + готовая сумка)
